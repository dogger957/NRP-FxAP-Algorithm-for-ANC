# NRP-FxAP-Algorithm-for-ANC
The official implementation of the NRP-FxAP algorithm for Active Noise Control

## Dataset and Model

Due to the large size of the data files, the dataset used in the paper is hosted on cloud storage.  
The download link is provided below.

The cloud storage contains:

- The **model path** used in the experiments (projection channel number = 6).
- The **measured test dataset** recorded at a vehicle speed of **50 km/h**.

Download link:  https://box.nju.edu.cn/d/e83255ad79d44a328020/
